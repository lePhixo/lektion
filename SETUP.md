# Lektion

Kostenlose, statische Lernheft-Website für Netlify. Keine Zugangsdaten erforderlich.

## Netlify
Netlify → Add new project → Import from Git → GitHub → lePhixo/lektion. Build command leer lassen; Publish directory `.`.

## Aktueller Stand
- Lokale Profile und gespeicherte Lernblätter
- Suche und Fachfilter
- Browser-Spracherkennung (de-CH; Dialekterkennung nicht garantiert)
- Strukturierte, regelbasierte Lernblätter, Kopieren und Drucken

## Noch nicht integriert
- Allgemeines KI-Modell zum eigenständigen Erklären beliebiger Themen
- Google-Anmeldung / Firebase-Synchronisierung
- Zuverlässige Schweizerdeutsch-Transkription

Die lokalen Notizen werden nur im jeweiligen Browser gespeichert. Keine sensiblen Zugangsdaten in GitHub-Dateien ablegen. Aufnahmen nur mit Einwilligung.
